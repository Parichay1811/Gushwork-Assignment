# Mangalam HDPE Pipes — Product Website

A modern, responsive product showcase website for **Mangalam HDPE Pipes & Fittings**.  
This website highlights premium HDPE piping solutions with interactive UI components, technical specifications, product galleries, and a lead generation contact form.

---

## 📌 Project Overview

This project is a fully responsive static website built using:

- HTML5  
- CSS3  
- Vanilla JavaScript  
- Google Fonts (Inter & Playfair Display)  

The website is designed to:

- Showcase HDPE pipes and related solutions  
- Display technical specifications  
- Provide interactive product gallery  
- Highlight manufacturing process  
- Present testimonials and resources  
- Generate leads via contact form

## 🧠 JavaScript Functionality

The `script.js` file handles:

- Sticky header behavior  
- Mobile menu toggle  
- Image gallery switching  
- Image zoom lens effect  
- FAQ accordion toggle  
- Applications carousel navigation  
- Process step active switching  
- Smooth scroll  
- Scroll-based fade-in animations  

All functionality is written using vanilla JavaScript (no external libraries).
